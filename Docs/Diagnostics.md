# 诊断码

所有诊断码前缀 `DNS`,四位数字。码一旦发布不得改判语义 —— 需要改判就新开一个码,旧码标 deprecated。
每个码在本文件都要有:一句话说明、一段中文散文解释(什么情况下会触发、为什么这是错的、怎么修)。

文档站的诊断页从本文件生成,缺中文散文会硬报错。

## 段位

| 段 | 归属 | 说明 |
|---|---|---|
| 1000–1999 | 词法 | 非法字符、未闭合字符串、缩进不一致 |
| 2000–2999 | 语法 | 解析失败、意外的 token、块结构错误 |
| 3000–3999 | 名字与引用 | 未声明的 fact、找不到的节点、重复 ID、跳转到不存在的目标 |
| 4000–4999 | 表达式与类型 | 类型不匹配、未定义的运算、比较不可比的值 |
| 5000–5999 | 图与可达性 | 死链、不可达分支、章节不可达、记忆链不可完成、孤儿内容 |
| 6000–6999 | 本地化与资源 | 本地化 key 撞车、缺配音引用、引用不存在的资产 |
| 7000–7999 | 演出(Stage) | 轨道时序越界、相机跳变没有遮罩覆盖、恢复操作未声明 |
| 8000–8999 | 生成与写回 | 资产生成失败、源文件写回冲突、往返不等价 |
| 9000–9999 | 工具链 | 命令行参数、文件访问、监视器与多编辑器冲突 |

## 码表

### DNS1001

缩进里出现了全角空格(U+3000)。

**中文散文**:中文输入法在中文模式下按空格打出来的是全角空格,肉眼和半角空格几乎一样,但它不是缩进。这一行的层级因此无法判定。把行首的全角空格换成普通空格即可;编辑器会提供一键替换。

### DNS1002

Tab 和空格混用作缩进。

**中文散文**:一个文件只能用一种缩进字符:要么全是空格,要么全是 Tab。同一行里两者混用,或者这一行用的和文件其他地方用的不一样,都会报这个码。层级是靠数字符算出来的,混用会让"看起来对齐"和"实际层级"分家。统一成一种即可。

### DNS1003

缩进量不是文件缩进单位的整数倍。

**中文散文**:文件的缩进单位由第一处缩进决定(比如两个空格)。之后每一行的缩进必须是它的整数倍,三个空格就说不清是一级还是两级。按单位补齐或删掉多余的空格。

### DNS1004

字符串没有闭合。

**中文散文**:`"…"`、`“…”` 或 `「…」` 打开后到行尾都没有找到配对的闭合引号。字符串不能跨行;补上闭合引号,或者检查是不是引号种类没配对(`「` 只能用 `」` 关)。

### DNS1005

出现了无法识别的字符。

**中文散文**:在命令、表达式这些非文本区里出现了语言不认识的字符,常见的是从别处粘贴进来的特殊符号。台词和旁白里什么字符都可以;只有行首关键字之后的部分、条件、修饰符受限。删掉或换成对应的半角符号。

### DNS2001

这一行缩进在一个不开块的行下面。

**中文散文**:只有 `dialogue`、`if`、选项这类块头的下面可以再缩进。`set`、`->`、属性行这些是叶子,它们下面缩进的行无处归属。要么把它提到同级,要么它本来就该属于上面某个块头。文件第一行就缩进也会报这个码。台词和旁白是例外:它们下面更深的裸文本行是同一句的续行。

### DNS2002

块头下面什么都没有。

**中文散文**:`if`、`else`、`journal`、`on accept`、轨道名这些行打开一个块,但下一行没有比它更深的内容。空块通常是漏写了内容或缩进写错了。补上内容,或删掉这个块头。空的选项(`- 告辞` 后面什么都不做)不算这个错。

### DNS2003

这一行放错了地方。

**中文散文**:每个块只接受自己那几种行:顶层只接受声明,`quest` 里只接受任务属性,`stage` 里只接受轨道。这一行的形状和它所在的位置对不上——最常见的是缩进少了一级,让它从块里掉了出来。检查缩进,或者看看它是不是该换个关键字。

### DNS2004

同一个修饰符在一行里出现了两次。

**中文散文**:行尾修饰符每种最多一个:一个 `if`、一个 `once`、一个 `#id`。写了两次的话哪个算数说不清。留一个。

### DNS2005

选项出现在对话之外。

**中文散文**:以 `- ` 开头的行是玩家选项,只能出现在 `dialogue` 块(或它的 `if` / 选项体)里面。在顶层或任务块里遇到它,多半是缩进丢了,让它脱离了原来的对话。把它缩回对话里。

### DNS2006

台词里的 ` if ` 被当作了普通文本(提示)。

**中文散文**:行尾的 `if` 只有在后面能解析成条件、而且条件里引用了至少一个已声明的名字时,才算条件修饰符;否则整段是台词。这条提示告诉你这一行有个 ` if `,被当成了文本。如果它确实是条件,检查名字有没有声明、表达式有没有写对;如果它就是台词内容,可以忽略,或者把整句用引号包起来让提示消失。

### DNS2007

期望某个东西,却遇到了别的。

**中文散文**:语法层面的通用错误:`if` 后面没有条件、`fact 名:` 后面不是类型、`wait` 后面不是时长、括号没配对……消息里会说明期望什么、实际遇到什么。按消息补上缺的部分。

### DNS2008

一行或一个表达式已经完整,后面还有多余的内容。

**中文散文**:`set x = 1 2` 里的 `2`、`-> 节点 多余的话` 里的后半截,都是语法上没有位置的东西。检查是不是少了运算符,或者多余的部分本该在下一行。

### DNS2009

这种行不允许这个修饰符。

**中文散文**:`once` 只属于选项,`for 时长` 和 `@演出` 只属于台词和旁白。放错了行的修饰符会被记录下来,但不会生效。删掉它,或者把它挪到正确的行上。

### DNS2010

`else` 前面没有 `if`。

**中文散文**:`else` 和 `else if` 必须紧跟在同一层级的 `if` 或 `else if` 后面。中间隔了一句台词,或者连续写了两个 `else`,都会断开这条链。调整顺序,或把中间的内容挪进分支里。

### DNS3001

引用了一个没有声明的 fact。

**中文散文**:条件、`set`、`implied`、目标里用到的名字必须先用 `fact` 声明。拼写错误、忘了声明、或者分组 fact 忘了写前缀(`墨梅册.第一页` 不能只写 `第一页`)都会报这个码。校验器能查可达性、能查"从未被写"的前提,就是每个 fact 都有声明。

### DNS3002

说话人不是已声明的角色。

**中文散文**:形如 `名字: 台词` 的行会被当成台词,`名字` 必须是 `character` 声明过的角色。两种修法:确实是这个角色在说话,就加一行 `character 名字`;它其实是旁白(比如"注意:门开了"),就在行首加 `> `。刻意不让它静默变成旁白,是为了抓住角色名的拼写错误。

### DNS3003

跳转或 `visited()` 指向不存在的对话。

**中文散文**:`-> 名字` 和 `visited(名字)` 里的名字必须是某个 `dialogue` 块。改名之后忘了改引用是最常见的原因;改名请在声明上加 `was 旧名`,校验器会提示所有还在用旧名的地方。

### DNS3004

同一个名字声明了两次。

**中文散文**:角色、fact、章节、任务、对话、演出共用一个命名空间,而且是项目范围内全局唯一——不同文件里也不能重名。消息会说明它已经被声明成了什么。改掉其中一个。

### DNS3005

引用了不存在的任务。

**中文散文**:`accept` / `complete` / `fail`、`subquest`、以及表达式里的 `任务.completed` 都要求任务已用 `quest` 声明。检查拼写或补上声明。

### DNS3006

引用了不存在的演出。

**中文散文**:`play 名字` 和台词行尾的 `@名字` 必须指向一个 `stage` 块。检查拼写或补上声明。

### DNS3007

`was` 指向的旧名字仍然被声明着。

**中文散文**:`was 旧名` 的意思是"这个东西以前叫旧名,存档和引用要迁移过来"。如果旧名还有声明,那就不是改名而是两个东西,迁移表会打架。要么删掉旧的声明,要么去掉 `was`。

### DNS3008

保留字被用作名字。

**中文散文**:`set`、`if`、`title`、`camera` 这些词在语言里有固定含义,不能拿来当角色、fact 或节点的名字。中文名字永远不会撞上保留字,这也是推荐用中文命名的原因之一。

### DNS3009

引用了不存在的章节。

**中文散文**:`advance 名字`、`advance -> 名字`、`chapter == 名字` 和 `chapter in (...)` 里的名字必须是某个 `chapter` 块。检查拼写或补上声明。

### DNS4001

类型不匹配。

**中文散文**:给 bool fact 赋数字、拿 bool 和数字比大小、对非数字用 `+=`、`and` 两边不是条件……凡是值的种类对不上都报这个码。消息里会说明两边各是什么。fact 只有四种类型:bool、int、float、tag;写表达式时对照声明看一眼。

### DNS4002

tag 值不在 fact 声明的集合里。

**中文散文**:tag fact 用 `in (甲, 乙, 丙)` 声明它能取的值,之后赋值、比较、`in` 列表里只能用这几个。写了集合外的名字,通常是拼写错误或者忘了往集合里加新值。声明了 tag 类型却没写集合,也报这个码。

### DNS4003

常量超出了 fact 声明的范围。

**中文散文**:`range 0..10` 的 fact 直接赋 99 是明显的错误,编译期就能抓住。运行时的写入会被钳到范围内,但源码里写死的越界值应该改掉。

### DNS4004

这两种值没有大小可比。

**中文散文**:`<`、`<=`、`>`、`>=` 只对数字有意义。tag 之间没有顺序,bool 也没有。想表达"状态到了某一步",用 `==` 或 `in (...)`。

### DNS4005

内置函数用错了。

**中文散文**:内置只有三个:`visited(对话)`、`random(最小, 最大)`、`chance(概率)`。参数个数或种类不对、或者调用了不存在的函数名,都报这个码。任务状态用 `任务.completed` 这类属性写法,不是函数。

### DNS4006

这里必须是常量。

**中文散文**:fact 的默认值和章节 `implied` 里的值要在编译期算出来存进资产,不能引用其他 fact、章节或随机数。换成字面量或集合成员。

### DNS5008

选项组里没有一个"保底"选项。

**中文散文**:一组选项如果每一个都带 `if` 或 `once`,就可能出现全部被隐藏的时刻,玩家面前一个选项也没有。规则是每组至少留一个既无条件也非一次性的选项。运行时如果仍然出现全空(条件恰好全假),整组会被跳过,直接落到选项组之后的那一行。

### DNS8001

资产无法创建或保存。

**中文散文**:生成阶段建包或写盘失败。常见原因:目标目录不可写、文件被另一个编辑器进程锁住、包名含非法字符。看消息里的路径,关掉占用它的进程后重试。

### DNS9002

无法读取源文件。

**中文散文**:命令行给的路径不存在或没有读取权限。检查路径是否相对于项目目录,或者用绝对路径。

### DNS9101

测试里的 `set` 写了剧情自己的 fact。

**中文散文**:test 块里的 `set` 模拟的是游戏代码写账本,而游戏代码只能写 `extern` fact——剧情自己的 fact 要由剧情改,测试不能绕过去替它改。如果要的是测试的起始状态(比如"村长好感已经是 2"),把它写在 `given` 块里;`given` 以剧情的身份写入,不受归属限制。如果这个 fact 确实由游戏系统喂进来,就在声明上加 `extern`。
