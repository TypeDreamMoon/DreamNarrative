# 诊断码

所有诊断码前缀 `DNS`,四位数字。码一旦发布不得改判语义 —— 需要改判就新开一个码,旧码标 deprecated。
每个码在本文件都要有:一句话说明、一段中文散文解释(什么情况下会触发、为什么这是错的、怎么修)。

文档站的诊断页从本文件生成,缺中文散文会硬报错。

## 段位

| 段 | 归属 | 说明 |
|---|---|---|
| 1000–1999 | 词法 | 非法字符、未闭合字符串、缩进不一致 |
| 2000–2999 | 语法 | 解析失败、意外的 token、块结构错误 |
| 3000–3999 | 名字与引用 | 未声明的 fact、找不到的节点、重复 ID、跳转到不存在的目标 |
| 4000–4999 | 表达式与类型 | 类型不匹配、未定义的运算、比较不可比的值 |
| 5000–5999 | 图与可达性 | 死链、不可达分支、章节不可达、记忆链不可完成、孤儿内容 |
| 6000–6999 | 本地化与资源 | 本地化 key 撞车、缺配音引用、引用不存在的资产 |
| 7000–7999 | 演出(Stage) | 轨道时序越界、相机跳变没有遮罩覆盖、恢复操作未声明 |
| 8000–8999 | 生成与写回 | 资产生成失败、源文件写回冲突、往返不等价 |
| 9000–9999 | 工具链 | 命令行参数、文件访问、监视器与多编辑器冲突 |
